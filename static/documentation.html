System & Operational Reference Manual

Technology Stack & Architecture

The Weena Loft Rental Engine is built using modern, fast, and self-contained languages and frameworks designed for performance and maintainability.

Python 3 Backend

Powered by FastAPI and run asynchronously via the Uvicorn server process on port 8000. Auto-generates standard OpenAPI Swagger documentation.

SQLite3 Relational Database

Relational file-based database (rental_system.db) managed on a separate visual explorer portal on port 8001.

Vanilla ES6 Javascript

Native browser API clients executing AJAX fetches, welcome screen setups, dynamic page tabs, and base64 picture encoders.

Glassmorphic CSS Styling

Custom CSS utilizing blurred backdrops, glowing shadows, dark mode layouts, and custom media wrappers for mobile compatibility.

Operational & Business Rules

📅 Rent Cycle & Collection

Rent is scheduled for collection on the 1st of every month. It is marked as due before the 7th. Reminders are broadcasted to all active tenants automatically.

⚠️ Overdue Penalties (5%)

Payments recorded on or after the 11th of the month trigger an automatic 5% late fee penalty warning, calculated dynamically on the unit's base rent.
